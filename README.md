# TeddyPups U.A.E.

A responsive website for a puppy brand, built with React, Vite and Tailwind CSS.

## Features

- Browse available puppies with filters for origin, breed and boy or girl
- Puppy detail pages with a WhatsApp enquiry button
- Gone home and happy families galleries
- How it works page and FAQ with search
- Contact form that opens WhatsApp with the message ready to send
- Animated dog mascot and paw-print cursor trail
- Works on mobile, tablet, and desktop
